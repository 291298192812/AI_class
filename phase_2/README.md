# سیستم پیشنهاد فیلم و کتاب
## بخش کدنویسی و آماده‌سازی داده‌ها

### ۱. معرفی پروژه
هدف این پروژه، آماده‌سازی داده‌های موردنیاز برای ساخت یک سیستم پیشنهاددهنده‌ی فیلم و کتاب است. در بخش کدنویسی، داده‌ها با استفاده از زبان Python پردازش و پاک‌سازی می‌شوند تا برای مراحل بعدی، از جمله طراحی الگوریتم پیشنهاددهنده و ارزیابی عملکرد آن، آماده باشند.

### ۲. فناوری‌های مورد استفاده
- **Python:** زبان برنامه‌نویسی پروژه
- **Pandas:** برای خواندن، پردازش و پاک‌سازی داده‌ها
- **Pathlib:** برای مدیریت مسیر فایل‌ها و پوشه‌ها
- **CSV:** قالب ذخیره‌سازی داده‌ها

### ۳. ساختار داده‌ها
داده‌های پروژه از چهار ستون اصلی تشکیل شده‌اند:

| نام ستون | توضیحات |
|---|---|
| `user_id` | شناسه‌ی کاربر |
| `item_id` | شناسه‌ی فیلم یا کتاب |
| `item_type` | نوع آیتم؛ `movie` یا `book` |
| `rating` | امتیاز کاربر، در بازه‌ی ۱ تا ۵ |

در صورت استفاده از فایل کاتالوگ آثار، اطلاعات تکمیلی مانند عنوان، ژانر، سال انتشار و زبان نیز می‌تواند در فایل جداگانه ذخیره شود.

### ۴. قابلیت‌های برنامه
برنامه‌ی `prepare_data.py` وظایف زیر را انجام می‌دهد:

1. بارگذاری داده‌ها از فایل CSV یا ایجاد داده‌های نمونه در صورت نبود فایل ورودی.
2. بررسی وجود ستون‌های موردنیاز.
3. حذف مقادیر خالی و رکوردهای ناقص.
4. تبدیل امتیازها به مقادیر عددی و حذف امتیازهای نامعتبر.
5. حذف رکوردهای تکراری مربوط به یک کاربر و یک آیتم.
6. مرتب‌سازی داده‌های پاک‌سازی‌شده.
7. تقسیم داده‌ها به مجموعه‌های آموزش و آزمون.
8. بررسی عدم هم‌پوشانی رکوردهای کاربر و آیتم بین دو مجموعه.
9. ذخیره‌ی گزارش مربوط به مراحل پاک‌سازی.

### ۵. نصب پیش‌نیازها
ابتدا Python را نصب کنید. سپس در ترمینال دستور زیر را اجرا کنید:

```bash
python -m pip install pandas
```

### ۶. نحوه‌ی اجرا
فایل `prepare_data.py` را در پوشه‌ی اصلی پروژه قرار دهید. سپس در همان پوشه دستور زیر را اجرا کنید:

```bash
python prepare_data.py
```

پس از اجرای موفق برنامه، فایل‌های خروجی در پوشه‌ی `data` ذخیره می‌شوند.

### ۷. فایل‌های خروجی

| نام فایل | کاربرد |
|---|---|
| `raw_data.csv` | داده‌های اولیه |
| `cleaned_data.csv` | داده‌های پاک‌سازی‌شده |
| `train.csv` | داده‌های آموزش |
| `test.csv` | داده‌های آزمون |
| `cleaning_report.csv` | گزارش آماری پاک‌سازی |

### ۸. روش تقسیم داده‌ها
در نسخه‌ی فعلی، تقسیم داده‌ها با نسبت تقریبی ۸۰ درصد برای آموزش و ۲۰ درصد برای آزمون انجام می‌شود. مقدار ثابت `random_state=42` باعث می‌شود تقسیم داده‌ها در اجراهای تکراری، در صورت یکسان بودن ورودی، قابل بازتولید باشد.

### ۹. اعتبارسنجی داده‌ها
برنامه پس از آماده‌سازی، موارد زیر را بررسی می‌کند:
- امتیازها در بازه‌ی ۱ تا ۵ قرار داشته باشند.
- نوع آیتم فقط فیلم یا کتاب باشد.
- یک زوج یکسان از شناسه‌ی کاربر و آیتم هم‌زمان در مجموعه‌ی آموزش و آزمون قرار نگیرد.

### ۱۰. محدودیت‌ها
- داده‌های نمونه‌ی داخل برنامه ساختگی هستند و نباید به‌عنوان امتیازهای واقعی کاربران معرفی شوند.
- این برنامه به‌تنهایی الگوریتم نهایی پیشنهاد فیلم و کتاب را پیاده‌سازی نمی‌کند؛ وظیفه‌ی اصلی آن آماده‌سازی داده‌هاست.
- کیفیت پیشنهادها باید در مراحل بعدی پروژه و با استفاده از روش ارزیابی مناسب بررسی شود.

### ۱۱. نتیجه‌گیری
در این بخش، یک فرایند اولیه برای دریافت، پاک‌سازی، اعتبارسنجی و تقسیم داده‌ها پیاده‌سازی شده است. خروجی‌های این برنامه می‌توانند به‌عنوان ورودی بخش الگوریتم پیشنهاددهنده و ارزیابی سیستم مورد استفاده قرار گیرند.

**نکته:** داده‌های نمونه برای آزمایش عملکرد کد ساخته شده‌اند و لزوماً نماینده‌ی سلیقه‌ی کاربران واقعی نیستند.

قدم به قدم کد

۱. ساخت پوشه خروجی

اگر پوشه data وجود نداشته باشد ساخته می‌شود. exist_ok=True جلوی خطای تکراری را می‌گیرد.

۲. ساخت داده نمونه

۲۰ رکورد ساختگی از ۷ کاربر و ۷ آیتم تعریف می‌شود. این داده فقط برای تست است.

۳. تبدیل به DataFrame و ذخیره داده خام

داده به DataFrame تبدیل و در data/raw_data.csv ذخیره می‌شود. index=False یعنی ستون ایندکس در فایل نوشته نشود.

۴. تمیز کردن داده

چند کار پشت سر هم انجام می‌شود:

· حذف مقادیر خالی: ردیف‌هایی که user_id یا item_id یا rating ندارند حذف می‌شوند.
· تبدیل امتیاز به عدد: اگر امتیازی غیرعددی باشد به NaN تبدیل و بعد حذف می‌شود.
· فیلتر بازه معتبر: فقط امتیازهای بین ۱ تا ۵ نگه داشته می‌شوند.
· حذف تکراری‌ها: اگر یک کاربر به یک آیتم چند بار امتیاز داده باشد، فقط اولین رکورد می‌ماند. این کار مهم است چون اگر یک جفت کاربر-آیتم هم در آموزش و هم در آزمون باشد، نتیجه آزمون واقعی نخواهد بود.
· مرتب‌سازی: داده بر اساس user_id و item_id مرتب و ایندکس‌ها از نو شماره‌گذاری می‌شوند.

در پایان داده تمیز در data/cleaned_data.csv ذخیره می‌شود.

۵. تقسیم به آموزش و آزمون

۸۰٪ داده به صورت تصادفی برای آموزش انتخاب می‌شود و ۲۰٪ باقی‌مانده برای آزمون. random_state=42 باعث می‌شود هر بار اجرای کد نتیجه یکسان باشد. دو فایل train.csv و test.csv ذخیره می‌شوند.

۶. بررسی صحت تقسیم

جفت‌های (کاربر، آیتم) در آموزش و آزمون به مجموعه تبدیل می‌شوند و با assert بررسی می‌شود که اشتراکی نداشته باشند. یعنی هیچ تعاملی هم در آموزش و هم در آزمون نیست.

· از pathlib.Path استفاده شده تا مسیرها روی هر سیستم‌عاملی کار کنند.
